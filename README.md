# Páginas para negocios

Soy Serch. Quise reunir tres maneras distintas de resolver una presencia web: una clínica dental, una consulta de psicología y un estudio de uñas. Me sirven para practicar cómo cambian la jerarquía, el lenguaje y la interacción según el negocio.

No son clientes reales. Son muestras ficticias para enseñar diseño y código sin inventar testimonios ni resultados comerciales.

## Cómo las construí
Partí de una necesidad por muestra y trabajé estructura, estilos y comportamiento por separado. Apliqué diseño de software con componentes sencillos, conocimientos de redes para la publicación y criterios de ciberseguridad: dependencias reducidas, política de contenido restrictiva y ausencia de formularios que simulen enviar.

Conservé imágenes de demostración y recursos locales. Las imágenes no acreditan instalaciones ni personas reales de esos negocios.

## Ver y probar
Abre index.html o visita [la galería](https://sergioh-devsec.github.io/paginas-para-negocios/).
Las pruebas se ejecutan con Node.js: node --test tests/*.test.cjs.

Los ejercicios básicos incluidos en basicos/ también tienen ahora repositorios independientes; no los incorporé al portafolio comercial.

## Límites
No hay reservas, pagos ni servicios médicos reales. Los controles muestran interacción de demostración. Mi siguiente paso es validar necesidades con un negocio real y publicar evidencia solo con su permiso.
